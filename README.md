# Одиссея

Бесплатный онлайн-кинотеатр. Фильмы берутся из нескольких легальных источников:

| Источник | Что это |
| --- | --- |
| **Wikimedia Commons** | фильмы в общественном достоянии и под свободными лицензиями |
| **YouTube** | фильмы, которые киностудии официально выложили бесплатно (например, «Мосфильм») |
| **Internet Archive** | архив фильмов в общественном достоянии |

Каталог (названия на русском, годы, жанры, страны, режиссёры, постеры) собирается из
[Wikidata](https://www.wikidata.org) и хранится в `src/data/catalog.json`. Поиск и фильтры
работают прямо по этому файлу, поэтому сайт не зависит от доступности сторонних API.
На странице фильма можно переключаться между источниками: если один сервис недоступен, можно выбрать другой.

## Запуск

```bash
npm install
npm run dev
```

## Обновить каталог

```bash
npm run catalog
```

Скрипт `scripts/build-catalog.mjs` заново выгружает фильмы из Wikidata (несколько минут).
После этого закоммитьте обновлённый `src/data/catalog.json`.

## Деплой на Vercel

1. Запушить репозиторий на GitHub.
2. На vercel.com → **Add New… → Project** → выбрать репозиторий → **Deploy**.

## Структура

- `scripts/build-catalog.mjs` — сборка каталога из Wikidata
- `src/lib/catalog.ts` — поиск, фильтры, источники видео
- `src/app/page.tsx` — главная
- `src/app/catalog/page.tsx` — каталог: поиск, источник, жанр, страна, десятилетие
- `src/app/film/[id]/page.tsx` — страница фильма с плеером
- `src/components/Player.tsx` — плеер с переключением источников
